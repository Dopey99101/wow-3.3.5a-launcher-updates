# RealmVoyager Launcher Updates

The home for **RealmVoyager launcher updates for World of Warcraft 3.3.5a**.

Find new launcher releases here, including updated artwork, layout improvements, new features, and bug fixes for a smoother experience with your Original or UltraHD client.

## Download the latest version

**You only need the latest launcher release.** Each release contains the complete launcher and includes the improvements from previous versions. You do not need to download or install older releases first.

➡️ **[Get the latest launcher release](https://github.com/Dopey99101/wow-3.3.5a-launcher-updates/releases/latest)**

Open the release and download the **RealmVoyagerLauncher ZIP** under **Assets**. The GitHub “Source code” downloads are not the ready-to-use launcher.

## Install or update your launcher

1. Close RealmVoyager and download the latest launcher ZIP.
2. Extract the entire ZIP into a new, permanent folder where you have permission to save files. Do not run the launcher from inside the ZIP.
3. Keep all included files and folders together, including `RealmVoyager.exe.config` and the `tools` folder.
4. Open **RealmVoyager.exe** from the new folder. If needed, click **Locate game** and select your existing Original or UltraHD game executable.
5. Click **Desktop shortcut** to create a shortcut to the updated launcher. Use that shortcut for future launches.
6. Click **Check updates** to check supported addon updates, then click **Play** when ready.

Updating the launcher does not require reinstalling your game. Keep your existing game folder and personal settings.

## Launcher updates and addon updates

This repository provides **updates to the RealmVoyager application itself**. Install launcher releases manually using the steps above; the launcher does not currently update itself automatically.

Inside RealmVoyager, **Check updates** checks supported addon releases from the [individual addon update repository](https://github.com/Dopey99101/wow-335a-addon-updates-individual/releases). An addon check does not update the launcher, the game executable, or HD graphics packs.

For a newly installed client downloaded through RealmVoyager, you must click **Check updates** and let the required addon updates and final check finish successfully before Play becomes available.

## Requirements

- Windows 10 or Windows 11, 64-bit.
- .NET Framework 4.8.
- A compatible WoW 3.3.5a build 12340 Original or UltraHD client, or a client installed through RealmVoyager's supported installation controls.

RealmVoyager uses on-screen buttons and menus. It has no in-game slash or chat commands.
